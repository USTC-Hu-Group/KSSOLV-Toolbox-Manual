# KSSOLV Toolbox Traditional Chinese manual

This generated edition uses `zh-TW` (Taiwan Traditional Chinese). Edit [the Simplified Chinese sources](../manual-zh-CN/README.md), then run the following commands from the repository root:

```sh
python tools/translate_zh_tw.py
python tools/download_tw_fonts.py
python build.py --language zh-TW
```

Use `python tools/translate_zh_tw.py --check` to check synchronization or `--build` to regenerate and compile in one command. Regeneration overwrites generated files. All figures, screenshots, examples, code listings and literal inputs remain unchanged. The index retains the original pinyin sorting.

See the [repository README](../../README.md) for dependencies, output paths and the language roadmap. You can also run `python build.py` inside this directory.
