# KSSOLV Toolbox 中文用户手册编写计划

当前正式稿为 **V0.5.0，313 页**。下列各轮记录按其完成时的页数与文件指纹保留；最新版本文字和图注修订见本文件末尾。

编制日期：2026-10-20。范围：独立应用程序、MATLAB® 工具箱与 KSSOLV Toolbox Online。交付形式：可维护的中文 LaTeX 项目、可检索且带书签的 PDF、案例文件、截图来源清单及审校记录。目标读者：初次接触第一性原理计算的使用者。

## 编写原则

- 先解释概念，再说明何时使用，接着用操作步骤和真实示例讲解，最后说明如何阅读结果。避免机械罗列菜单、编造数值和反复提醒风险。
- 所有功能、按钮名称、格式、参数默认值、保存和会话行为均核对当前源码与运行界面。运行截图不以绘制的界面或生成图冒充；示意图另行标明。
- 保留当前工作区已有变更，只在手册目录、研究记录和计划文件内新增工作。不得新增 Java/JVM 依赖或编译型源代码。文档构建使用无需 JVM 的 TeX 与 Python 工具。
- 将事实核对、语言编辑、版面检查分开记录。未实测能力必须注明核验范围；实测失败必须解决或明确列为待验证，不能据此宣称出版验收通过。

## 步骤与验收标准

### 1. 资料盘点与功能边界

工作：检查已有指南、菜单、工作流节点、结构样例、安装方式、Online 会话及品牌素材；并行建立计算、建模、Online 三份事实依据。分析参考 PDF 的封面、版权页、目录、正文、表格、截图、末页。

验收：每个拟写模块均有源码或实机依据；记录版本、操作系统与入口；列出不能实测的依赖，不把其他软件的功能写成 KSSOLV 的事实。

### 2. 书稿结构与中文 LaTeX 样式

工作：建立独立 LaTeX 项目，设计封面、扉页/版本说明、目录、章节标题、步骤、表格、图注、提示、页码、附录和封底。中文采用清晰的宋体正文与黑体标题，拉丁文字协调搭配。制作包含长标题、表格、截图和代码的样张。

验收：样张成功编译；中文无缺字；图像与文字不越界；字号适合连续阅读；内外页边距、蓝绿色、品牌标识、图注和页码一致。模板与内容分离，正文可逐章维护。

### 3. 实机操作与图像采集

工作：使用本机独立应用程序与真实 Online，按案例顺序采集工作区、结构、建模对话框、工作流、参数、计算和结果等不同状态；截图保留清晰文字与上下文。必要时配套局部放大与说明标记，避免反复使用同一画面。

验收：截图清单记录文件、入口、操作、用途、采集时间和是否已有仓库素材；同图不承担多个无关步骤；无密钥和个人账户信息；不把源码推测或重建网页称为实机截图。每个核心任务至少有对应实机图与操作后检查点。

### 4. 正文与案例编写

拟定章节：阅读本手册；安装和启动；Online 入门；认识工作区；结构与项目；第一项计算；计算基础与参数；工作流与任务；晶体和分子建模；表面、缺陷与复杂结构；结果与体数据；远程计算；设置与日常工作；常见问题；附录（格式、单位、快捷键、术语和索引）。按证据可调整章名和顺序。

案例链：导入简单晶体→保存项目→建立并运行 SCF→检查收敛；超胞与点缺陷；表面与真空层；分子几何与选择；能带/体数据结果；Online 上传、计算、保存与下载。仅将实际支持并能核对的案例写为可执行教程。

验收：每例含目的、起始文件、具体操作、输入和单位、预期界面、结果解读与保存方式；数值结果有实测来源；概念在首次出现时解释；桌面与 Online 差异写在对应操作附近。内容详尽而不过度重复，不以页数或截图数量代替完整性。

### 5. 第一轮技术交叉审校

工作：至少两名子智能体独立核对菜单、参数、公式、单位、保存与会话规则、案例可执行性；主编复核争议并修改正文。

验收：每项问题有位置、依据、处理和关闭状态；没有未处理的事实性严重问题；确认没有引入 Java/JVM 或新增编译源代码。适用的 MATLAB 非图形验证以 `-nojvm` 执行，无法执行时如实记录。

### 6. 第二轮语言、教学和版面审校

工作：子智能体分别检查中文行文、术语、普通读者能否跟随、图文配合、章节衔接与重复；主编逐页查看渲染页面，修正孤行、溢出、空白、表格和图片可读性。修改后重新编译，并复核受影响页及目录。

验收：全文无占位符、断裂交叉引用、缺图、未定义书签和明显错别字；所有页面完成视觉核验；封面、目录、正文和尾页形成完整书籍；每轮问题均留记录，必要时继续下一轮。

### 7. 成书交付与可重复构建

工作：整理 LaTeX 源码、品牌与截图资产、案例、构建说明、最终 PDF 和审校记录。确认链接、PDF 文字检索、书签及页码，记录最终版本依据。

验收：在无 JVM 的文档构建链中可从源码重新生成；最终 PDF 与源码一致；交付文件可打开；所有必需案例/截图/审校条件通过才标记完成。若真实运行环境阻碍某条件，保留为未完成项并明确报告，不称为出版定稿。
