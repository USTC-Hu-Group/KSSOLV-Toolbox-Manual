# 纳米结构配套案例

本组使用配套KSSOLV Toolbox的MATLAB建模API，在R2026b、Apple Silicon、`-nojvm`模式实际生成。没有进行GUI操作、DFT、钝化或几何弛豫，没有新增编译型代码或依赖。

## 教学文件

下表结构均提供同名`.json`与`.cif`。JSON保留原生周期与构建信息；CIF读回当前均为三向周期，只用作几何交换。

| 文件主名 | 用途与本次实际结果 |
| --- | --- |
| `nano-graphene-60` | 两位点石墨烯输入，a=2.46Å、γ=60°、c=15Å，pbc=true/true/false。 |
| `graphene-armchair-w3-l2` | armchair、宽3、轴向2、每侧真空5Å；24C，pbc=false/true/false。 |
| `graphene-tube-4-0-l2` | (4,0)、轴向2、每侧横向真空6Å；32C，pbc=false/false/true。 |
| `nano-Cu-fcc-input` | 复用既有Cu-fcc.cif，a=3.61Å、4Cu的输入副本。 |
| `Cu-wire-001-r3-l2` | [001]、半径3Å、轴向2、每侧真空4Å；24Cu，一维周期。 |
| `Cu-dot-r3` | 半径3Å、每侧真空4Å；13Cu，三个方向非周期。 |
| `Cu-void-host-2x2x2` | Cu的2×2×2宿主，32Cu、盒长各7.22Å、三维周期。 |
| `Cu-void-r2p7` | 从上述宿主删除中心半径2.7Å球内原子；去13留19，保留原晶格与三向周期。 |

`nano_examples.m`重现构建、预定输入对照及结构读回；`verify_nano_examples.m`只读取现存八对JSON/CIF，不重新构建。输入和结果数据为`nano-examples-results.json`，独立读回检查为`nano-examples-verification.json`。

## 带与管的关键数值

本组使用等价的60°石墨烯基底。由既有120°的`graphene-layer.json`调用`build_supercell`，矩阵`[1 0 0;1 1 0;0 0 1]`、行列式1，改变b为a+b，仍是2sites，体积和周期距离保持不变。这是现有API支持的换基，不改材料参数或产品源码。

纳米带：盒长`[16.15,8.521689973239,10]`Å，实际碳宽跨度6.15Å；两个非周期方向两侧各5Å真空。以1.65Å为检查界限，16C有3近邻、8个边缘C有2近邻；最短周期距离1.420281662206Å。

纳米管：半径1.566084640024Å，盒长`[15.132169280049,15.132169280049,8.521689973239]`Å；32C均有3个1.65Å以内近邻，最短周期距离1.393202130652Å。曲率会使卷曲后直线键长不同于平片。该小管用于结构操作练习，不是弛豫后的稳定结构数据。

本轮也按原稿参数对原始120°输入作了明确对照：带的轴长4.92Å、边缘近邻分布与本教程armchair例不同；管虽命令完成，但轴长13.017096450438Å、最短接触0.929792603603Å，近邻数混为2/3/4。这组不合适几何的诊断输出已归档，不作为本仓库可继续使用的教学结构。重新运行时，附加诊断文件写入`output/reference-runs/`。复现本节请使用60°输入。

## 铜结果的检查

- 纳米线：横向盒长13.415Å、轴向7.22Å；最短周期近邻2.552655480083Å。
- 铜团簇：三个盒长各11.61Å，原子跨度各3.61Å；中心Cu有12个2.8Å内近邻，12个表面Cu各有5个。
- 空洞：删除球以分数坐标(.5,.5,.5)为中心，剩余原子距中心的最短周期距离3.61Å。原子位置离散，因此该值不必等于输入2.7Å。最短原子间距仍2.552655480083Å。

## 重新运行

先按[案例运行说明](README.zh-CN.md#在-matlab-中重复计算)配置软件路径，再从本手册仓库根目录以`-nojvm`启动MATLAB后运行：

```matlab
run('docs/manual-zh-CN/examples/nano_examples.m')
run('docs/manual-zh-CN/examples/verify_nano_examples.m')
```

所有新生成文件保存在本手册仓库的`output/reference-runs/`，随书参考文件保持不变。

两个脚本均检查JVM关闭。编写时的构建与独立导入运行均退出0；原始过程日志已归档。本仓库保留`nano-examples-results.json`与`nano-examples-verification.json`，供直接核对或重新运行。

八对JSON/CIF全部读回。JSON保留坐标、晶格、元素、周期与构建元数据值；CIF位点数/元素正确、标签唯一，原生周期和构建元数据不能据此视为保留。CIF与JSON的周期距离谱最大差约2.840672×10⁻⁵Å，本次明确检查界限为0.001Å。本节数值可对照上述两份随附JSON；未交付的编写档案不作为公开文件引用。
