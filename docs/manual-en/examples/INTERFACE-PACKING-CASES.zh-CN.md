# 同材双层与水/乙醇装填练习

本组使用配套KSSOLV Toolbox的MATLAB API在R2026b、Apple Silicon、`-nojvm`中实际构建并导入核对。结构用于学习输入、候选与几何检查，没有进行GUI操作、DFT计算或分子平衡。

## 从一个石墨烯层到双层

`graphene-layer.json`采用仓库现有测试的二维层：六方晶格a=2.46 Å、盒高15 Å，两个C的分数位置为(0,0,0.5)、(1/3,2/3,0.5)。面内周期、法向非周期，最短面内周期原子间距约1.42028166 Å，面内面积约5.24083933 Å²。

先用“插入结构”的参数逻辑，将同一层沿笛卡尔z方向平移3.35 Å，最小距离0.5 Å。`graphene-inserted.json`含4个位点，层间距3.35 Å，保持原盒高15 Å，剩余空白高度11.65 Å。这一步展示已知相对位置时的直接插入。

再用“堆叠异质结构”的参数逻辑，底层和顶层都选择这一石墨烯层。本例是同材双层，不是异种材料界面。输入如下：

| 参数 | 值 |
| --- | --- |
| 层间距 | 3.35 Å |
| 法向空白高度 | 15 Å |
| 最大面内应变 | 0.03，即3% |
| 最大面内重复 | 2 |
| 最大旋转搜索角 | 0° |
| 排序 | 面积 |
| 候选序号 | 1 |

实际得到10个候选组合。候选1面积5.24083933 Å²、应变0、旋转0°、预计4个位点；应用后`graphene-stacked.json`确有4个位点，层编号为1、1、2、2，盒高18.35 Å，层间距3.35 Å，空白高度15 Å。该例未设置面内滑移，两层对应原子在面内对齐。

候选表也包含高于3%应变的其他组合；列表中的每一项并不都满足最终应用条件。应先检查应变、面积和原子数，再选择。例如候选2、3的应变约52.49%，不适合本例0.03的上限；候选4、5、6接近零应变，但需要8个位点。完整10项数据保存在`interface-packing-examples-results.json`。

三份结构JSON都已通过应用使用的`StructureIO`重新导入，晶格、分数位置、周期标记和层编号与保存前一致。

## 固定种子的10水/10乙醇

水分子来自随书`water.xyz`。`water-packing.json`保留完全相同的坐标，并明确保存两条O–H单键。乙醇使用上轮已核对的`ethanol-optimized.json`，共9个原子。

数量模式选择每类10个分子，种子固定为23，最小分子间接触1.2 Å，一批装填。脚本事先限定最多两个密度：先尝试1 g/cm³；若失败，只把密度改为0.1 g/cm³，保持种子、数量和接触不变，不搜索其他种子。

本次在1 g/cm³时抛出`KSSOLV:Modeling:PackingInfeasible`，未得到结果。0.1 g/cm³时成功，保存为`water10-ethanol10-packed.json`：

| 检查项 | 实测结果 |
| --- | --- |
| 分子数 | 水10、乙醇10，共20 |
| 总原子数/组成 | 120；C20H80O20 |
| 总质量 | 640.8372 amu |
| 立方盒边长 | 21.995420586 Å |
| 体积 | 10641.352074 Å³ |
| 质量/体积独立重算密度 | 0.1000000000 g/cm³ |
| 最短分子间接触，含周期最小映像 | 4.099018055 Å，原子14/93 |
| 跨边界最短分子间接触 | 4.486220125 Å，原子15/31，映像偏移(0,−1,0) |
| 分子内部任意原子对距离的最大变化 | 约4.0×10⁻¹⁵ Å |

这是便于检查的低密度初始装填，不将0.1 g/cm³解释为水/乙醇混合液的平衡密度。接触检查区分分子内部与不同分子，不能拿O–H键长与1.2 Å的分子间接触要求直接比较。

输出保留组分编号、分子编号及分子内原子映射，所有原子、分子数量与内部几何均已核对。当前装填输出结构没有另存全局显式成键表；两种组分的显式拓扑保存在输入JSON中。输出JSON读回后，晶格、原子坐标、周期标记与编号映射一致。

## 重现与记录

先按[案例运行说明](README.zh-CN.md#在-matlab-中重复计算)配置软件路径，再从本手册仓库根目录以MATLAB `-nojvm`运行：

```matlab
run('docs/manual-zh-CN/examples/interface_packing_examples.m')
```

所有新生成文件保存在本手册仓库的`output/reference-runs/`，随书参考文件保持不变。

脚本保留默认密度的失败标识与消息，也保留低密度成功结果、10项层匹配候选、密度独立复算及跨周期接触检查。公开定量结果见`interface-packing-examples-results.json`。原始运行日志及内部核查汇总已归档，不随本仓库提供。
