\chapter{配置应用环境}\label{ch:remote}
\index{Yuancheng jisuan@远程计算}

完成本地结构和工作流练习后，可以按需要调整界面、连接材料数据库，或把计算提交给已经配置好的远程环境。这些功能分别解决不同的问题：设置决定应用如何与个人服务配合，远程计算决定工作流在哪里执行，日志与帮助则用于理解当前状态并交流问题。

本章先介绍普通用户经常使用的设置，再介绍完整 MATLAB 工具箱中的远程提交。远程部分以教学集群为例；使用独立应用或 Runtime Online 的读者，可以继续使用当前环境完成计算，并阅读本章最后的日志与帮助。

\section{调整应用设置}

\subsection{打开设置并保存修改}

在 \ui{主页} 的环境区域点击 \ui{设置}。通用页包含界面语言和对话服务设置，Materials Project 页用于数据库访问；连接账号服务的 Online 环境还提供账号页。

更改后点击 \ui{确认} 才会保存。点击 \ui{取消} 或直接关闭设置窗口，会放弃本次尚未确认的修改。再次打开窗口时，会重新读取已经保存的值，可以据此核对实际采用的设置。

\subsection{切换界面语言}
\index{Jiemian yuyan@界面语言}

\begin{steps}
\item 打开 \ui{主页 → 设置 → 通用}。
\item 在语言区域选择需要的界面语言。
\item 点击 \ui{确认}，保存选择。
\item 保存正在编辑的项目，然后重新启动应用。
\item 检查工具栏与面板标题是否已经使用新的语言。
\end{steps}

语言在下次启动时生效。桌面应用关闭后重新打开即可；Online 中 \ui{退出 KSSOLV Toolbox} 只是暂时返回入口，原实例仍在运行。Online 用户需要先保存项目，再按平台的注销或重新启动流程进入新的实例。

\section{连接对话服务}
\index{Duihua fuwu@对话服务}

\subsection{选择服务类型}

命令行窗口除了执行可用命令，还可以在配置后使用对话服务。应用支持 Ollama 和 OpenAI 兼容服务。前者常用于单位或个人管理的模型服务，后者使用提供方给出的 API 基础地址、密钥与模型名称。

不需要为了导入结构或运行 DFT 工作流而先配置对话模型。对话可以帮助解释术语、整理思路或阅读提示；计算节点的数值结果仍由工作流产生，材料结论应结合模型和计算结果判断。

\subsection{设置 OpenAI 兼容服务}

开始前，从服务提供方取得基础地址、个人 API Key 和有权使用的模型。这里使用“OpenAI 兼容”指接口形式，实际提供方和模型以账号中可用的服务为准。

\begin{steps}
\item 在 \ui{设置 → 通用} 中找到大语言模型区域，选择 OpenAI 兼容类型。
\item 在 \ui{API 基础地址} 中输入提供方给出的根地址。
\item 在 \ui{API Key} 中输入个人密钥。
\item 点击 \ui{测试连接} 或刷新模型列表，等待状态提示。
\item 从 \ui{使用的模型} 中选择可用模型，核对名称后点击 \ui{确认}。
\item 回到命令行窗口，用一个简短的概念问题检查服务是否能正常回答。
\end{steps}

图\ref{fig:settings-service-fields}展示一组OpenAI兼容服务字段：类型为\ui{OpenAICompatible}，基础地址为\url{https://api.deepseek.com/v1}，模型名为\ui{deepseek-flash}。地址和模型按所用服务填写，连接是否可用以测试反馈和一次实际回复为准。

\begin{figure}[!htb]
\centering
\includegraphics[width=\linewidth]{publication-assets/crop-172fba0260bf90759552.png}
\caption{Online通用页的对话服务字段实例。公开基础地址和模型名称分别填写，密钥已遮挡。}

基础地址不要再附加 \file{/chat/completions} 或 \file{/models}。这些路径由应用请求时使用，重复填写会使地址错误。连接成功却没有模型可选时，检查账号权限和服务是否返回模型列表；这与“网络完全无法连接”是不同情况。

密钥输入框通常以遮挡形式显示。若需更正可以使用显示按钮短暂查看，完成后恢复隐藏。如需删除已经保存的OpenAI密钥，先选择另一种不使用它的服务，再清空密钥并点击\ui{确认}；仍选OpenAI兼容服务时，设置页会要求填写可用密钥。截图或课堂投影时保持密钥隐藏。

\subsection{设置 Ollama}

Ollama 需要一个已经运行并能由应用访问的服务。桌面用户可以使用本机服务，Online 则需使用服务器能访问的地址。浏览器在自己的电脑上，并不意味着服务请求也从这台电脑发出。

\begin{steps}
\item 在模型类型中选择 Ollama。
\item 填写服务根地址，不附加某个具体 API 路径。
\item 测试连接并刷新模型列表。
\item 选择服务已经提供的模型，点击 \ui{确认}。
\item 回到命令行窗口发送简短问题，检查状态与回复。
\end{steps}

Online 中的 \file{localhost} 指运行工具箱的服务器或容器，不能用它指向个人笔记本上的 Ollama。课程若提供统一模型服务，直接使用教师给出的服务器地址。

\subsection{刷新模型列表}

模型输入框既可从列表选择，也允许按服务提供方给出的名称填写。修改地址或密钥后，先点击刷新图标，等待当前服务重新返回模型；不要把旧列表中的名称当作新地址一定可用的模型。测试尚在进行时，可以使用同一个测试按钮停止等待，再检查输入。

连接状态回答的是服务请求是否成功，模型名回答的是准备使用哪个模型，两者需要分别确认。服务可连接但列表为空时，可能没有返回可枚举模型；此时按课程提供的准确名称填写，再用一个简短问题检查。界面提示本发行包没有对话组件时，按提供该功能的发行方式使用，不影响本书的结构与DFT教程。

\subsection{在命令窗口提问}\label{sec:chat-use}

对话和普通命令共用一个输入区，但由开头符号区分。普通MATLAB表达式直接输入；以一个美元符号开头表示带已有对话上下文提问，以两个美元符号开头表示本次不带已有对话历史。美元符号是输入的一部分，不需要先切换另一张聊天页面。

\begin{steps}
\item 在设置中确认服务与模型后，打开命令行窗口，等待输入区可用。
\item 输入\literalinput{$ 请解释平面波截断能的含义}，按Enter，观察等待状态及逐步出现的回复。
\item 需要继续追问时，输入\literalinput{$ 为什么还需要检查k点收敛}，使问题沿用当前对话。
\item 希望独立询问另一件事时，输入\literalinput{$$ 请说明分数坐标的三个分量}。
\item 将需要保留的解释整理到实验笔记，再回到结构或工作流执行真正的建模与计算。
\end{steps}

回复结束后，状态区可能显示实际响应的模型名称。回答中的代码是可阅读和核对的材料，不等于项目已经按它完成了计算。确认服务设置、提出清楚问题和运行数值任务各有入口；首次学习时分别完成，较容易知道当前是哪一步得到了结果。


\subsection{理解修改后的对话}

点击确认应用新的服务或模型后，下一次提问会建立新的对话客户端与上下文。需要保存的解释、笔记或结论，应另行整理到自己的学习记录中，不能把对话历史当成项目中的完整实验记录。

流式回复中途断开时，界面会显示未完成或失败信息。可以检查服务连接后重新提问，不必把半段回复当作完整答案。计算方法章节中的关键定义和参数含义，应以软件文档及所用方法的资料为依据。

\section{设置 Materials Project 访问}
\index{Materials Project@Materials Project}

Materials Project 是结构来源之一。应用的数据库导入入口需要个人访问设置；直接从本机导入 CIF 或 XYZ 则不需要这一项。

\begin{steps}
\item 打开 \ui{设置 → Materials Project}。
\item 点击 \ui{查看我的 API Key}，在浏览器中进入个人 API 页面。
\item 按数据库网站要求登录个人账户，复制自己的 API Key。
\item 返回应用，将值填入 API Key 输入框并点击 \ui{确认}。
\item 从 \ui{主页 → 结构 → 从 Materials Project 导入结构…} 打开检索界面。
\item 用课程指定的化学式或材料标识查找结构，查看信息后再导入。
\end{steps}

设置页保存的是访问服务的凭据，不是某个具体结构。结构导入后仍应核对组成、晶胞和原子数，并为项目中的结构取一个容易识别的名称。数据库中可能存在同一化学式的不同晶型，选择时以研究对象为准。

\section{认识远程计算}

\subsection{Online 与远程集群的关系}

完整 MATLAB 中运行的工具箱提供 \ui{远程} 菜单，用于把当前工作流提交到另一个 MATLAB 环境或计算集群。当前编译的独立应用和 Runtime Online 不显示此菜单。以下远程配置和提交步骤面向完整 MATLAB 工具箱用户。

Online 已经在服务器上运行，浏览器用户无需先配置 SSH。应用运行位置与集群提交是两件事：前者决定当前工作空间在哪里，后者将另一个任务交给特定计算环境。

远程作业是一次提交的记录，包含工作流、提交目标、状态与输出等信息。提交成功只表示远端接受了任务；任务可能仍在排队，也可能在开始运算后遇到问题。完成计算后，还要把结果取回当前项目，再保存项目。

\subsection{选择执行模式}

\begin{table}[htbp]
\centering
\caption{远程执行模式与适用环境}
\begin{tabularx}{\linewidth}{lX}
\toprule
模式 & 适用环境 \\
\midrule
标准 & 本地 MATLAB 通过 MATLAB Parallel Server 与 Slurm 提交，本地与远端各计算组件使用相同 release。\\
Bridge & 由远端 MATLAB 向自己的集群配置提交，远端 MATLAB 与其 worker 使用相同 release。\\
Mirror & 在单个远端节点运行普通 MATLAB，不要求 MATLAB Parallel Server。\\
Cloud & 使用已经配置并验证可用的云端 MATLAB Cluster Profile。\\
\bottomrule
\end{tabularx}
\end{table}

优先采用课题组已经验证的方式。一个普通单节点 MATLAB 环境可以考虑 Mirror；已有 Parallel Server 与 Slurm 的教学集群按管理员建议选择标准或 Bridge。Cloud 依赖已准备好的 Profile，并不因为选择该模式就自动建立一个云集群。

远程计算需要对应 MATLAB 产品与许可，本地 MATLAB 环境要求 Parallel Computing Toolbox。版本协调和集群侧安装由管理员准备，学生使用时重点检查选择的配置是否与课程环境一致。

\section{建立教学集群配置}
\index{Jiqun peizhi@集群配置}

\subsection{准备远端信息}

新建配置前，向管理员确认连接地址、认证方式、远端 MATLAB 根目录与可写作业目录。如果使用 Profile，还需确认它的名称；使用 Slurm 则可能需要分区、账户、QoS 和最长运行时间。

配置名称应说明用途，例如“教学集群”，而不只是“服务器一”。同一单位的登录节点、计算节点和共享存储可能不同，按管理员给出的信息填写，不要根据个人电脑的目录推测远端路径。

\subsection{填写集群配置}

\begin{steps}
\item 打开 \ui{主页 → 远程 → 配置远程集群…}。
\item 点击 \ui{新增}，填写配置名称并选择执行模式。
\item 在 \ui{连接} 页按管理员要求填写主机和认证设置。
\item 在 \ui{计算} 页填写当前模式的 MATLAB、Profile、作业目录及资源信息。
\item 选择 KSSOLV 部署方式：附带当前工具箱，或使用远端已安装的工具箱。
\item 点击 \ui{测试连接}，检查状态说明。
\item 需要时点击 \ui{探测资源}，查看回填内容；检查正确后点击 \ui{保存}。
\end{steps}

MATLAB 根目录指软件的安装根目录，不是 \file{bin/matlab} 可执行文件。作业目录应位于远端可写位置，并能被相应计算节点访问。Worker 数量应遵守站点允许的资源与许可，不应仅按机器总核数填写最大值。

\ui{测试连接} 检查连接与登录步骤，已有 Profile 的配置也可能进行最小作业检查。\ui{探测资源} 则读取远端 MATLAB 和资源信息。两者用途不同：测试连接不替代资源探测，探测回填也不会自动保存配置。

\subsection{选择工具箱部署方式}

Attach Current Toolbox 会把当前工具箱附带到远端，适合远端没有相应版本的情况。某个工具箱版本第一次使用时可能需要较长传输，后续作业可以复用已经准备的代码。

Cluster Installed 使用管理员已安装的工具箱，需要填写正确根目录并确认版本兼容。课程统一管理的环境通常会给出明确选择；普通学生无需自行更改远端共享程序目录。

登录脚本用于初始化远端环境，例如加载站点的 MATLAB 模块。计算命令模板和提示规则用于特殊路由或额外认证，只有管理员确实要求时才填写。普通直连能够工作时，保留简单路径更容易理解与维护。

\section{练习：提交并取回一次计算}
\index{Yuancheng zuoye@远程作业}

本例使用已经完成的小型硅结构工作流，沿用前面章节的参数。重点是掌握提交与结果管理，不在远程提交的同时更换材料和计算方法。

\subsection{提交前保存并选择目标}

\begin{steps}
\item 打开此前完成的项目与工作流，核对结构输入、节点连接和主要参数。
\item 保存项目，给本次工作流取一个容易识别的名称。
\item 打开 \ui{主页 → 远程 → 使用远程计算}，选择“教学集群”等已保存配置。
\item 如需再次检查连接，使用 \ui{测试当前集群}。
\item 点击 \ui{运行}，等待提交提示，并记下显示的作业 ID。
\end{steps}

检查点是已经产生远程作业记录，而不是仅看到运行按钮变忙。没有选择远程配置时，“不使用”表示在当前 MATLAB 所在环境执行。切换配置前核对名称，避免把比较用的练习提交到另一套环境。

\subsection{跟踪远程作业}

\begin{steps}
\item 打开 \ui{主页 → 远程 → 远程作业与结果…}。
\item 在列表中选择刚提交的作业，核对工作流、集群和提交时间。
\item 点击 \ui{刷新}，查看排队、运行或完成等状态。
\item 点击 \ui{查看 Diary}，阅读计算输出，检查是否有参数或收敛信息。
\item 若任务设置需要更正，先通过 \ui{取消作业} 结束相应作业，再修改工作流并重新提交。
\end{steps}

状态为 Unknown 时，表示应用暂时无法明确读取状态，不等于已经计算失败。先检查网络和调度环境，再刷新。Diary 暂无输出也可能是任务尚未开始，判断时结合提交时间和队列状态。

% SCREENSHOT: 真实小型作业的状态列表与 Diary；选择可读的计算段落，避免整页密集终端文字。

\subsection{取回并导入结果}

\begin{steps}
\item 确认作业已完成，选择 \ui{取回并导入}。
\item 等待结果传输和导入完成的提示。
\item 返回项目浏览器，找到与本次工作流对应的计算数据或图形。
\item 打开收敛曲线、能量等相关结果，检查是否符合前面章节的判读方法。
\item 保存项目，使取回结果保留在 \file{.ks} 文件中。
\end{steps}

同一作业已经导入时，应用会提示结果已存在，避免重复添加。导入需要当前项目中仍有对应工作流，因此提交后应保留原项目，避免在取回前删除或替换整个工作流。

取回成功只完成了数据传输。科学上的检查仍需观察 SCF 收敛、能量和所用参数。如果一次远程结果与本地练习不同，先比较结构、赝势与节点设置，再讨论计算环境的差别。

\subsection{整理作业记录}

作业窗口中的 \ui{清理本地包} 删除本地传输代码包，不会取消远端作业。\ui{删除记录} 只删除本地记录，也不会删除远端工作目录。需要结束计算时使用 \ui{取消作业}，不要用删除记录代替。

已有作业保留识别原提交环境所需的信息。之后修改配置，不会让先前的任务自动转到另一台服务器。阶段性整理时，先取回需要的结果并保存项目，再清理已经不再需要的传输内容。

\section{在远程命令行窗口中工作}

\ui{远程执行命令行窗口的命令} 会使用所选直连 SSH 配置建立长驻 MATLAB 会话。它与工作流提交相互独立，适合短小的环境检查或交互运算。只有 Profile、没有直连信息的配置不能使用该功能。

\begin{steps}
\item 选择一个已经验证的直连配置。
\item 打开命令行窗口，启用 \ui{远程执行命令行窗口的命令}。
\item 输入一个简短检查命令，例如 \texttt{version}。
\item 观察带有 \texttt{[remote]} 标记的输入输出，确认命令在远端执行。
\item 完成后关闭远程执行，回到普通命令方式。
\end{steps}

同一远程会话中的命令共享 base workspace。切换目标、关闭远程命令功能或关闭命令行窗口会结束该会话。需要长期保留的数据应保存到合适文件；希望重复运行的科学步骤，适合组织为工作流。

\subsection{从界面确认当前状态}

资源区域提供 \ui{文档}、\ui{社区} 与 \ui{帮助} 等入口。\ui{关于 KSSOLV} 可以查看产品信息；\ui{检查更新} 用于了解新版本，具体安装仍按分发包和部署方的更新方式进行。Online 的这些外链由浏览器打开，返回工作区后可以继续编辑项目。

遇到问题时，先区分发生在导入、参数设置、运行、取回还是显示阶段。清楚写出“哪一步、看见什么、预期什么”，通常比笼统描述“不能运行”更容易交流。

\subsection{整理日志}

\begin{steps}
\item 保存当前项目，记录应用版本与所用模式。
\item 从 \ui{帮助} 菜单选择 \ui{打开日志}。
\item 桌面应用在系统默认程序中打开日志；Online 在页内显示日志，并可刷新或下载完整文件。
\item 找到问题发生时间附近的内容，保留相关提示。
\item 准备一张能看清问题的截图，以及能够重现问题的小项目。
\item 点击 \ui{请求支持}，在系统邮件应用中整理并发送说明。
\end{steps}

\ui{请求支持} 打开的是带有主题的邮件草稿，是否发送以及附上哪些文件由用户决定。如果计算机没有配置默认邮件应用，可以使用资源入口提供的其他联系渠道。提交材料前检查截图和日志中是否含个人凭据。

\subsection{查看许可和更新信息}

在\ui{主页 → 帮助}中选择\ui{查看许可}，可以阅读当前产品的许可文本。需要引用、分发或在另一种环境使用时，以该发行包提供的许可和部署说明为准。

\ui{检查更新}用于查看更新信息，\ui{关于 KSSOLV}用于确认本机正在运行的产品版本。检查到新版本后，先保存当前项目，再按第\ref{ch:install}章的对应平台步骤更新；浏览器部署的版本则由部署方管理。帮助中的\ui{示例}或环境中的某些扩展入口若呈灰色，表示这一发行版没有从该按钮提供操作；随书示例仍可从本书的examples目录导入。


\subsection{常见情况的处理顺序}

对话服务认证失败时，检查基础地址、密钥和模型权限；模型列表为空时，检查服务确实提供了可用模型。远程连接失败时，核对认证和登录脚本；提交失败时，再查看分区、账户、Profile 与版本要求。作业已完成却无法导入时，确认打开的是原提交项目，并查看 Diary 和导入提示。

把每次检查保持在一个明确范围内，可以避免一次同时修改许多设置。问题解决后，重新运行最小练习，再继续较大的项目；把最终采用的配置与参数保存在项目和实验记录中，后续复现也更方便。
