# O–H参数放置与石墨烯/h-BN匹配

本组在MATLAB R2026b、Apple Silicon、`-nojvm`中实际运行，使用当前产品的参数命令。没有进行GUI拖动、DFT、吸附能计算或几何弛豫。原Pt表面与石墨烯输入直接读取之前的配套文件，没有重新生成。

## 分清c偏移与表面法向高度

原`Pt111-slab.cif`的前两个晶格矢量定义(111)表面，其法向为(1,1,1)/√3，但c矢量沿全局z方向。当前放置和候选搜索的`height`参数沿c偏移。因此，原斜胞的offset=2 Å实际只对应约1.15470054 Å的表面法向高度。`Pt111-OH-c-offset.json`只用于比较这一差别，不作为真正2 Å法向顶位的参考。

参考宿主`Pt111-normal-c.json`使用现有“重定义晶胞”命令建立：a、b不变，第三矢量改为c+6a+6b。这是行列式1的整数基底变换，没有扩胞，仍为4个Pt位点。原子笛卡尔坐标与体积变化均为0，周期距离最大变化约1.78×10⁻¹⁵ Å；新的c与表面法向平行至约10⁻⁹的数值误差。矩阵与完整检查见报告和脚本。

## 可复现的法向O–H放置

片段输入`oh-fragment.mol`直接采用内置“O-H fragment”：O在(0,0,0)、H在(0.96,0,0) Å，含一条单键。采用中性双重态保存这个有限片段；不把它当作已完成表面成键的电子结构模型。

在`Pt111-normal-c.json`上使用以下参数：

| 参数 | 值 |
| --- | --- |
| 位点类型/候选 | ontop / 1 |
| 锚点高度 | 2 Å |
| 锚点原子 | 1，即O |
| 取向原子 | 2，即H |
| 方向 | `1 1 1`，本例的表面法向 |
| 最小允许距离 | 0.5 Å |

结果保存为`Pt111-normal-c-OH-outward.json`，含Pt4OH共6个位点。实测O法向高度2.00000000 Å、H法向高度2.96000000 Å，两者横向偏差均约2.30×10⁻⁹ Å；O–H长度0.96 Å、方向与法向点积为1，最短Pt–片段周期接触2 Å。结果原子坐标、晶格和吸附坐标元数据已重新导入核对。

这里的`1 1 1`属于本例的全局笛卡尔方向；换表面或坐标系后，应重新确认法向。`0 0 1`表示全局z方向，不能通用于所有表面。

直接查看最终几何时，可使用`Pt111-OH-outward.cif`。这份CIF由已保存的向外结果导出，读回实测仍为6个位点、Pt4OH；O/H法向高度约1.99999997/2.96000009 Å，O–H周期距离约0.96000012 Å。它保留晶体几何，不保留片段的显式化学键和吸附命令元数据。此处核对来自源模式导入，并未声称桌面GUI已显示验收。

`Pt111-normal-c-OH-ontop.json`另保留取向原子为0的放置。它只使O处于2 Å法向顶位，保留片段原来的O–H方向；可与向外定向结果比较。

## 几何吸附候选

在同一法向胞上，以顶位、桥位、空位型(hollow)候选，高度`1.8 2.1 2.4` Å、转角步长30°、锚点1、取向原子0、最小接触0.6 Å、最多200项、种子0进行原稿中的参数搜索。评分使用默认几何接触模型，不使用能量模型。

实际保留144项几何候选；全部通过独立周期接触核对，O–H长度保持0.96 Å，锚点高度沿真实法向符合输入。`Pt111-OH-candidate-1.json`是排名第一的几何候选：hollow、该类型候选2、高度2.4 Å、转角60°，最短Pt–片段周期接触约2.88462591 Å。这个排名只表示本次几何评分顺序，不表示稳定吸附构型或最低吸附能。

## 与h-BN的异材匹配

随附`hBN-layer.json`采用编写时软件课程案例中的理想层参数：a=2.50 Å、c=15 Å，B/N分数位置(0,0,0.5)、(1/3,2/3,0.5)。本例不另引入材料数值。石墨烯读取先前的`graphene-layer.json`，a=2.46 Å。

使用最大面内重复1、最大旋转0°、最大应变0.03、候选1、层距3.35 Å、空白15 Å，得到一个匹配候选。`graphene-hBN-stacked.json`含C2BN共4个位点，实际面内主应变0.016，即1.6%；h-BN面内晶格匹配到石墨烯晶格。层距和最短层间周期接触均为3.35 Å，法向盒高18.35 Å。输入和结果已重新导入核对。

## 保存与重现范围

O–H输入选用MOL，是因为当前原生JSON对只有一行的键表会丢失矩阵形状：`[1,2,1]`读回成为3×1，而分子拓扑检查要求N×3。该现象已在单独的只读导入脚本中复现。结果结构JSON的坐标、组成与吸附元数据数值可读，但其单键元数据同样读为3×1；本组不宣称单键数组形状完全往返。

先按[案例运行说明](README.zh-CN.md#在-matlab-中重复计算)配置软件路径，再从本手册仓库根目录用MATLAB `-nojvm`运行：

```matlab
run('docs/manual-zh/examples/adsorption_bn_examples.m')
run('docs/manual-zh/examples/verify_adsorption_bn_examples.m')
run('docs/manual-zh/examples/orient_oh_example.m')
run('docs/manual-zh/examples/export_oh_cif.m')
```

所有新生成文件保存在本手册仓库的`output/reference-runs/`，随书参考文件保持不变。

前者生成参数放置、候选及异材匹配；第二个脚本只读随书持久化结果；第三个脚本只在已保存宿主上补做向外定向，不重跑搜索；最后一个脚本只导出并读回最终CIF。定量报告为`adsorption-bn-examples-results.json`、`adsorption-bn-persistence-results.json`、`oh-outward-placement-results.json`、`oh-outward-cif-results.json`。以上JSON均随本目录提供；原始运行日志与内部核查汇总已归档。
