# 扭转双层与莫尔超晶格配套案例

这些结构由配套KSSOLV Toolbox的建模命令`twist_moire`在MATLAB R2026b、Apple Silicon、`-nojvm`中实际生成。没有进行GUI操作、DFT、层间弛豫或能带计算。独立读取脚本检查已保存文件，不重新构建。

## 文件与起点

| 文件 | 用途 |
| --- | --- |
| `twist-graphene-bottom.json/.cif` | 两位点底层石墨烯输入。 |
| `twist-graphene-top.json/.cif` | 相同几何的上层输入，便于在项目中区分角色。 |
| `graphene-twist-21p786789.json/.cif` | 目标21.786789°的28位点石墨烯双层。 |
| `graphene-twist-target22.json/.cif` | 目标22°的对照，实际选择与前者相同的周期结构。 |
| `graphene-hBN-twist-21p786789.json/.cif` | 石墨烯/h-BN扭转双层，28位点、C14B7N7。 |
| `twist-examples-results.json` | 输入、匹配整数、实际角、层数、尺寸和独立几何角度。 |
| `twist-examples-verification.json` | 五份JSON和五份CIF重新导入的核对记录。 |

两张石墨烯输入直接取已有`graphene-layer.json`，a=2.46 Å、面内夹角120°、c=15 Å、2个C位点，周期标记为`[true true false]`。h-BN直接取既有`hBN-layer.json`，a=2.50 Å、2个位点，不重新生成材料输入。

## 参数与主例结果

上下层都选石墨烯；目标角21.786789°，层间距3.35 Å，总真空15 Å，允许最大面内应变0.03，最大原子数200，最大周期匹配指数6。

| 检查项 | 本次实际结果 |
| --- | --- |
| 实际匹配角 | 21.78678929826181° |
| 目标角偏差 | 0.00000029826181° |
| 整数匹配 | m=2、n=1 |
| 底层2×2变换 | `[2 -1; -1 -3]`，行列式绝对值7 |
| 上层2×2变换 | `[1 -2; -2 -3]`，行列式绝对值7 |
| 组成、层数 | C28，两层，每层14个位点 |
| 面内晶格长度 | 6.50854822521889 Å、6.50854822521889 Å |
| 面内面积 | 36.68587533479335 Å²，是输入的7倍 |
| 面内夹角 | 60° |
| 面内应变 | 0 |
| 层间距 | 3.35 Å |
| 法向胞高、总空白 | 18.35 Å、15 Å |

还独立取两层一个原子的三个周期最近邻方向，计算相对方向差并按六方较小角比较，得到21.78678929826181°，与匹配记录一致。不是只读取目标输入来充当实际角。

## 两组参数对照

只把目标改为22°，仍生成28位点，实际角仍是21.78678929826181°；角偏差约0.21321070173819°。

保持原目标，但把最大原子数降至24，28位点候选被排除；本次改选m=1、n=0、4位点、接近0°的匹配。该受限结果只保留在报告，没有另交一个易与目标结构混淆的结果文件。命令完成不等于目标角被精确实现，比较时看实际结果与数量。

## 同一命令的异材例

底层石墨烯、上层h-BN，使用主例全部参数，实际仍选择m=2、n=1、实际21.78678929826181°。结果C14B7N7、28个位点；h-BN面内压缩到石墨烯共同晶格，主应变0.016，即1.6%。面内晶胞长度、层距、总空白与主例相同；独立近邻方向角同样约21.7867892982618°。

当前UI中“界面建模”是菜单分类，其中包含“插入结构”“堆叠异质结构”“扭转莫尔超晶格”和NEB路径入口。本次没有发现另一个独立名为“异质结”的建模执行命令。“堆叠异质结构”有候选表；扭转命令内部选取一组匹配，没有候选序号或排序参数。

## 保存格式

JSON读回保留晶格、坐标、二维周期标记、两层编号与`properties.moire`中的匹配信息。CIF导出副本先用现有接口建立唯一位点标签，避免重复标签；没有改变生产输出坐标或修改产品源码。

CIF经当前读取器读回后标为三向周期，也不保留moire元数据。五个CIF的周期距离谱与对应JSON之间最大差约3.75744×10⁻⁵ Å（输入单层约1.42028×10⁻⁵ Å），小于本次明确采用的0.0003 Å几何检查界限。它们不是与JSON逐分量、逐属性完全相同的持久化结果。继续二维建模比较优先使用JSON；CIF适合交换几何，进入计算前按目标方法确认法向边界和真空。

## 重现

先按[案例运行说明](README.zh-CN.md#在-matlab-中重复计算)配置软件路径，再从本手册仓库根目录用完整MATLAB的`-nojvm`模式运行：

```matlab
run('docs/manual-zh/examples/twist_examples.m')
run('docs/manual-zh/examples/verify_twist_examples.m')
```

所有新生成文件保存在本手册仓库的`output/reference-runs/`，随书参考文件保持不变。

第一份脚本生成主例、两个参数对照及异材例，保存五对JSON/CIF；第二份脚本只重新读取随书这十份参考结构并核对数量、周期标记、唯一标签、匹配信息和周期距离谱。公开定量结果与重新导入检查分别见`twist-examples-results.json`、`twist-examples-verification.json`；原始运行日志与内部哈希审计已归档。
