# 第七、八章建模配套案例

这些结构由配套KSSOLV Toolbox的建模命令在 MATLAB R2026b、Apple Silicon、`-nojvm` 中实际生成。它们用来核对组成、连接和几何，未进行密度泛函计算。本轮没有操作桌面或Online界面，也没有生成截图。

## 文件与用途

| 文件 | 内容与核对点 |
| --- | --- |
| `benzene-ring.json` | 六个C的芳香环骨架，边长1.4 Å，中心(0,0,0)，法向(0,0,1)，6条芳香键。 |
| `benzene.json` | 原骨架直接补氢，C6H6，12个原子、12条键，其中6条芳香键；保留自动放置氢的初始几何。 |
| `benzene-optimized.json` | 上述结构用通用分子模型优化后的结果；不能当作DFT优化结果。 |
| `pyridine.json` | 从苯删氢，将环序号1的C改为N（形式电荷0、sp2、芳香），再补氢；C5H5N，11个原子、11条键，其中6条芳香键。已明确设置总电荷0、单重态。 |
| `pyridine-optimized.json` | 上述中性单重态模型的通用分子模型优化结果。 |
| `ethanol-backbone.json` | C–C–O共线起始骨架，坐标(0,0,0)、(1.52,0,0)、(2.95,0,0) Å，两条单键。 |
| `ethanol-initial.json` | 对共线骨架补氢后的C2H6O，9个原子、8条单键。 |
| `ethanol-edited.json` | 按子树范围依次设置C–C距离1.52 Å、C–C–O键角109.5°、C–C–O–H二面角60°；O连接的H是序号9。这些是几何编辑值，不是后续优化固定的约束。 |
| `ethanol-cleaned.json` | 上一结构进行4轮规则整理后的状态。 |
| `ethanol-optimized.json` | 整理后进行通用分子模型优化的结果；C–C约1.54000026 Å、C–C–O约109.471731°，二面角约60.000299°。 |
| `Cu-fcc.cif` | Fm-3m、a=3.61 Å、单个非对称Cu位点(0,0,0)、占位率1展开的常规胞，4个位点。 |
| `Cu-vacancy.cif` | 对上述4个位点枚举空位，得到一个不等价候选、简并度4；文件含3个位点，最短周期接触约2.55265548 Å。 |
| `Pt-fcc.cif` | Fm-3m、a=3.92 Å、Pt(0,0,0)、占位率1，4个位点。 |
| `Pt111-slab.cif` | (111)、最小厚度8 Å、最小真空10 Å、居中、最简表面晶胞、终止1，结果4个位点和4层。 |

JSON文件可通过结构导入入口读取。它们保存分子及其显式键、化学属性和自旋信息。全部10份分子JSON均经`Molecule.from_file`与应用使用的`StructureIO`重新导入检查，原子数、键级、坐标一致；4份晶体CIF也经`StructureIO`重新导入检查。

## 优化报告如何读

本次统一采用最多200次迭代、最大力阈值0.001 kJ/(mol Å)、不固定原子。方法为`deterministic-lbfgs-backtracking`，参数为`kssolv-generic-mm-v2`，三次运行均无后备参数。

| 分子 | 迭代数 | 最终最大力 kJ/(mol Å) | 状态 |
| --- | ---: | ---: | --- |
| 苯 | 37 | 0.000227234211 | 达到力阈值 |
| 吡啶 | 38 | 0.000895168806 | 达到力阈值 |
| 乙醇 | 47 | 0.000672257882 | 达到力阈值 |

补氢后苯、吡啶的全部原子相对最佳拟合平面的最大偏差分别约0.72746 Å、0.73694 Å；优化后分别约4.62×10⁻⁷ Å、2.82×10⁻⁶ Å。这里的变化表明初始补氢几何需要检查。组成与键级正确、规则诊断无报错，都不能单独证明结构已达到期望的空间形状。优化数值属于上述通用分子模型，不作为芳香分子高精度参考几何。

## Pt表面的尺寸

本例只有一个终止候选，shift=0.5，面内面积约6.65384638 Å²。沿表面法向计算：

- 晶胞周期高度20.368917497 Å；
- 最外原子平面跨度6.789639166 Å；
- 周期相邻薄片的最外原子平面间空隙13.579278331 Å。

第三晶格矢量长35.28 Å，与法向不平行，因此不能直接把它当作法向胞高或真空厚度。构建输入中的8 Å按完整晶体重复单元取层；最外原子坐标之差是另一种厚度计量。另行验证固定底部一层时，仅序号1被标记固定。配套CIF是未固定的参考薄片，不宣称保留固定标记。

上列尺寸来自生成时的完整精度数据。当前CIF读取器对接近1/3、2/3的分数位置进行文字转换，重新导入后测得空隙13.579142539 Å，与生成值相差约0.000136 Å；核对报告同时保留两者。

## 格式与电子状态的已知差别

本次没有提供芳香分子的MOL版本：当前MOL写出会把1.5芳香键舍入成2，读回后环键变成双键。原生JSON已通过本轮往返核对。

按“苯→删除氢→C换N→加氢”操作得到的吡啶初始模型，电子数变回42，但会保留含奇数电子骨架的多重度2；其原始JSON读回会提示电荷/自旋不匹配。生成脚本通过现有MATLAB接口`set_charge_and_spin(0,1)`明确设为中性单重态，再保存吡啶参考文件。脚本未修改产品实现，也没有把这一步说成GUI已有对应按钮。

## 重现与记录

先按[案例运行说明](README.zh-CN.md#在-matlab-中重复计算)配置软件路径，再从本手册仓库根目录使用MATLAB `-nojvm`运行：

```matlab
run('docs/manual-zh/examples/modeling_examples.m')
run('docs/manual-zh/examples/verify_modeling_examples.m')
```

所有新生成文件保存在本手册仓库的`output/reference-runs/`，随书参考文件保持不变。

第一个脚本生成结构、`modeling-examples-results.json`及日志，第二个脚本重新读取随书参考文件，检查计数、键、乙醇目标几何、优化报告与Pt空隙，并重复验证上述格式和电子状态差别。公开的定量结果与独立读取检查分别见`modeling-examples-results.json`、`modeling-examples-verification.json`；原始日志及内部哈希审计已归档，不随本仓库提供。
